# Third-party notices

## Bundled in the mod jar

| Component | Use | Licence |
|---|---|---|
| [whisper-jni](https://github.com/GiviMAD/whisper-jni) 1.7.1 (io.github.givimad:whisper-jni) | Java bindings and native libraries for whisper.cpp, included as a nested jar | Apache License 2.0 |
| [whisper.cpp](https://github.com/ggml-org/whisper.cpp) 1.7.1 and ggml | Speech recognition, inside whisper-jni's native libraries | MIT |
| [OpenCC](https://github.com/BYVoid/OpenCC) dictionaries `TSCharacters.txt`, `TSPhrases.txt` | Traditional to Simplified conversion of Whisper's output (`assets/langmod/opencc`, unmodified, with its licence) | Apache License 2.0 |

## Data generated at build time

| Component | Use | Licence |
|---|---|---|
| [pypinyin](https://github.com/mozillazg/python-pinyin) 0.55.0 and its dictionaries | Pinyin readings in `assets/langmod/pinyin/items.json` and `chars.tsv` (generated by `tools/generate_pinyin.py`; pypinyin itself is not shipped) | MIT |
| Minecraft `zh_cn.json` (Mojang Studios) | The Chinese item names in `items.json` are Minecraft's own translations, looked up by translation key | Part of Minecraft; used as in any mod that ships vanilla text |

## Not bundled

- Whisper models (`ggml-*.bin`, MIT, OpenAI Whisper weights converted by the whisper.cpp project) are
  downloaded by the user.
- [Fabric Loader](https://github.com/FabricMC/fabric-loader) and [Fabric API](https://github.com/FabricMC/fabric)
  (Apache License 2.0) are separate mods.
- [Mod Menu](https://github.com/TerraformersMC/ModMenu) (MIT) is optional and only used in the
  development client.
- The optional `server` engine runs a `whisper-server` binary from a whisper.cpp release that the
  user downloads (MIT).
